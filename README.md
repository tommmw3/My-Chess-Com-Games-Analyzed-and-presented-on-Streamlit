# Chess.com Free Game Review

A chess.com game review clone web application designed for chess enthusiasts who want detailed game analysis. Built using **React**, **TypeScript**, and **Stockfish**, with a focus on accuracy and performance.

## Features

- **Server-based Stockfish Analysis:** The app uses server-side Stockfish evaluation for game analysis.
- **Move Classification:** Moves are classified as Brilliant, Best, Excellent, Good, Inaccuracy, Mistake, or Blunder.
- **Opening Detection:** Automatically detects and displays chess openings.
- **Accuracy Calculation:** Shows accuracy percentages for both players.
- **Interactive Chessboard:** Navigate through games with arrow navigation and move sounds.
- **Tailwind CSS for Styling:** Clean and responsive interface.

## Getting Started

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Razamindset/chess-com-game-review
cd chess-com-game-review
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

### Usage

1. Paste your PGN (Portable Game Notation) in the text area on the home page
2. Click "Analyze" to start the game review
3. Use the navigation buttons to step through moves
4. View move classifications and accuracy statistics

## Tech Stack

- **React** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **chess.js** - Chess logic
- **Zustand** - State management
